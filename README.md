# Nguyễn Đăng Khôi — Personal Portfolio

Portfolio cá nhân sử dụng HTML, CSS và JavaScript thuần, thiết kế responsive với phong cách dark editorial, typography hiện đại, hiệu ứng chuyển động nhẹ và các mục giới thiệu, hành trình, kỹ năng, dự án, kết nối.

## Cấu trúc
- `index.html` — nội dung và cấu trúc trang.
- `style.css` — giao diện, responsive, animation và hiệu ứng nền.
- `script.js` — menu mobile, reveal on scroll, thanh tiến trình cuộn và nút về đầu trang.

## Triển khai GitHub Pages
1. Mở **Settings → Pages** trong repository.
2. Chọn **Deploy from a branch**.
3. Chọn branch `main`, thư mục `/(root)`, nhấn **Save**.
4. Sau khi GitHub triển khai xong, truy cập:
   https://dangkhoinguyen7511.github.io/dang-khoi-portfolio/

## Cá nhân hóa trước khi chia sẻ
- Rà soát các mô tả để bảo đảm chúng phản ánh đúng trải nghiệm thực tế.
- Thay các mục dự án định hướng bằng sản phẩm thật, ảnh chụp và liên kết demo khi có.
- Có thể bổ sung ảnh đại diện, thành tích, chứng nhận và các kênh liên hệ phù hợp.
- Font Be Vietnam Pro và Space Grotesk được tải từ Google Fonts; giao diện vẫn có font dự phòng khi ngoại tuyến.
